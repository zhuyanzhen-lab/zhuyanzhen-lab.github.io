常见排序算法：实现思路与Python实现

数据结构 排序算法 Python
发布日期:   2026-07-29

系统梳理九种经典排序算法的核心思想、复杂度特征与 Python 实现。

复杂度总览

算法 平均时间 最坏时间 最好时间 空间 稳定性
冒泡排序 O(n²) O(n²) O(n) O(1) 稳定
选择排序 O(n²) O(n²) O(n²) O(1) 不稳定
插入排序 O(n²) O(n²) O(n) O(1) 稳定
希尔排序 O(n^1.3) O(n²) O(n) O(1) 不稳定
归并排序 O(n log n) O(n log n) O(n log n) O(n) 稳定
快速排序 O(n log n) O(n²) O(n log n) O(log n) 不稳定
堆排序 O(n log n) O(n log n) O(n log n) O(1) 不稳定
计数排序 O(n+k) O(n+k) O(n+k) O(k) 稳定
基数排序 O(d·n) O(d·n) O(d·n) O(n+k) 稳定

1. 冒泡排序（Bubble Sort）

思路： 重复遍历数组，每次比较相邻两个元素，若逆序则交换。每轮遍历将当前未排序部分的最大值”冒泡”到末尾。当某轮无交换发生时，数组已有序，可提前终止。

def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr

2. 选择排序（Selection Sort）

思路： 每轮从未排序部分选出最小元素，放到已排序部分的末尾。无论数据初始状态如何，比较次数恒定为 n(n-1)/2。

def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

3. 插入排序（Insertion Sort）

思路： 将数组视为”已排序前缀 + 未排序后缀”。每次取未排序部分的第一个元素，在已排序前缀中从右向左找到合适位置插入。对近乎有序的数据效率极高。

def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

4. 希尔排序（Shell Sort）

思路： 插入排序的改进版。设定递减的间隔序列（gap），先对间隔为 gap 的元素进行插入排序，逐步缩小 gap 直至为 1。前期大间隔排序使数据快速趋近有序，后期小间隔排序代价极低。

def shell_sort(arr):
    n = len(arr)
    gap = n // 2
    while gap > 0:
        for i in range(gap, n):
            key = arr[i]
            j = i - gap
            while j >= 0 and arr[j] > key:
                arr[j + gap] = arr[j]
                j -= gap
            arr[j + gap] = key
        gap //= 2
    return arr

5. 归并排序（Merge Sort）

思路： 分治策略。将数组递归拆分为两半，分别排序后合并。合并时比较两个有序子序列的首元素，依次取较小者放入结果数组。时间复杂度稳定为 O(n log n)，代价是需要 O(n) 辅助空间。

def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

6. 快速排序（Quick Sort）

思路： 分治策略。选取一个基准元素（pivot），将数组划分为”小于 pivot”和”大于 pivot”两部分，递归排序两部分。平均性能最优，但最坏情况（已有序 + 首元素为 pivot）退化为 O(n²)。随机选取 pivot 可有效规避。

import random

def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[random.randint(0, len(arr) - 1)]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

原地分区版本（更节省空间）：

def quick_sort_inplace(arr, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    if low < high:
        pi = partition(arr, low, high)
        quick_sort_inplace(arr, low, pi - 1)
        quick_sort_inplace(arr, pi + 1, high)
    return arr

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

7. 堆排序（Heap Sort）

思路： 利用最大堆结构。先将数组建为最大堆（建堆 O(n)），然后反复将堆顶（最大值）与末尾交换并缩小堆范围、下沉调整（每次 O(log n)）。原地排序，无需额外空间。

def heap_sort(arr):
    n = len(arr)

    # 建最大堆
    for i in range(n // 2 - 1, -1, -1):
        sift_down(arr, i, n)

    # 逐步取出堆顶
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]
        sift_down(arr, 0, i)
    return arr

def sift_down(arr, parent, size):
    while True:
        largest = parent
        left = 2 * parent + 1
        right = 2 * parent + 2
        if left < size and arr[left] > arr[largest]:
            largest = left
        if right < size and arr[right] > arr[largest]:
            largest = right
        if largest == parent:
            break
        arr[parent], arr[largest] = arr[largest], arr[parent]
        parent = largest

8. 计数排序（Counting Sort）

思路： 非比较排序。统计每个值出现的次数，根据累计频次确定每个元素的最终位置。适用于数据范围 k 不大的整数排序，时间复杂度 O(n+k)。

def counting_sort(arr):
    if not arr:
        return arr
    min_val, max_val = min(arr), max(arr)
    range_size = max_val - min_val + 1
    count = [0] * range_size

    for x in arr:
        count[x - min_val] += 1

    # 累计计数，确定稳定位置
    for i in range(1, range_size):
        count[i] += count[i - 1]

    output = [0] * len(arr)
    for x in reversed(arr):  # 逆序遍历保证稳定性
        count[x - min_val] -= 1
        output[count[x - min_val]] = x
    return output

9. 基数排序（Radix Sort）

思路： 非比较排序。按位（个位、十位、百位…）依次进行稳定排序（通常用计数排序作为子过程）。从最低位到最高位（LSD），每轮排序后数据在该位上有序，最终整体有序。适用于位数有限的整数。

def radix_sort(arr):
    if not arr:
        return arr
    max_val = max(arr)
    exp = 1
    while max_val // exp > 0:
        arr = counting_sort_by_digit(arr, exp)
        exp *= 10
    return arr

def counting_sort_by_digit(arr, exp):
    n = len(arr)
    output = [0] * n
    count = [0] * 10

    for x in arr:
        digit = (x // exp) % 10
        count[digit] += 1

    for i in range(1, 10):
        count[i] += count[i - 1]

    for x in reversed(arr):
        digit = (x // exp) % 10
        count[digit] -= 1
        output[count[digit]] = x
    return output

选型要点

数据量小或近乎有序： 插入排序，常数因子小，最好情况 O(n)。

通用场景、追求平均性能： 快速排序，缓存友好，实践中常数因子最小。

要求最坏情况保证： 归并排序或堆排序，稳定 O(n log n)。

要求稳定性： 归并排序（O(n) 空间）或计数/基数排序（限定数据类型）。

数据范围有限的整数： 计数排序或基数排序，可突破 O(n log n) 下界。
