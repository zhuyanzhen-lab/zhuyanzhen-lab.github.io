从NLP到大语言模型：技术范式的四次演变

NLP 大语言模型 Transformer 预训练模型
发布日期:   2026-08-12

自然语言处理（NLP）在过去七十年间经历了四次根本性的范式转变。每一次转变都不是简单的技术迭代，而是对”机器如何处理语言”这一核心问题的重新定义。本文梳理从规则系统到大语言模型的完整演进脉络，重点分析每个阶段的技术瓶颈与突破逻辑。

一、规则与统计时代（1950s–2010）

1.1 模块化 Pipeline 架构

早期 NLP 系统的设计思路是将语言处理分解为一系列串联的独立模块：分词 → 词性标注 → 句法分析 → 语义理解 → discourse 解析。每个模块使用手工规则或统计模型实现，模块之间通过定义好的接口传递中间结果。

这种架构的核心问题在于误差逐级累积。分词阶段的错误会传播到句法分析，句法分析的偏差会影响语义理解。更关键的是，每个模块都需要针对特定任务独立设计特征和训练模型，知识无法跨任务复用。一个在新闻语料上训练好的句法分析器，迁移到医学文本时往往需要完全重新设计。

1.2 统计模型的黄金时代

这一阶段的主流技术包括：

  • 隐马尔可夫模型（HMM）：用于序列标注任务（词性标注、命名实体识别），假设当前状态只依赖于前一个状态
  • 条件随机场（CRF）：克服了 HMM 的独立性假设限制，能够考虑整个观测序列的全局特征
  • n-gram 语言模型：基于滑动窗口的统计语言模型，用前 n-1 个词预测第 n 个词的概率
  • TF-IDF / BM25：基于词频和逆文档频率的文本检索方法

这些方法的共同局限是依赖人工特征工程。研究者需要凭借语言学知识手动设计特征（词性、句法树、语义角色标注），特征的质量直接决定了模型的性能上限。泛化能力弱、跨领域迁移困难是这一代方法的根本瓶颈。

二、词向量与深度学习（2013–2017）

2.1 分布式表示的突破

2013 年 Mikolov 等人提出的 Word2Vec 是 NLP 领域的第一个范式转变。它的核心贡献是将词映射为稠密的低维向量，使得语义关系可以通过向量运算捕捉：

vec("king") - vec("man") + vec("woman") ≈ vec("queen")

Word2Vec 基于分布式假设（Distributional Hypothesis）：上下文相似的词具有相似的语义。它通过两种架构实现：CBOW（用上下文预测中心词）和 Skip-gram（用中心词预测上下文）。GloVe 则从全局词共现矩阵出发，结合了全局统计方法和局部窗口方法的优势。

2.2 从离散符号到连续空间

词向量的意义不仅在于技术层面的改进，更在于认知层面的转变。词不再是离散的符号索引，而是连续向量空间中的点。语义相似性变成了向量距离，语义关系变成了向量方向。这为后续的深度学习模型提供了可微分的输入表示。

但 Word2Vec 存在一个根本缺陷：每个词只有一个固定向量，无法处理多义词。”bank”作为”银行”和”河岸”的向量表示是相同的，而这两种含义在上下文中的语义完全不同。这个缺陷需要上下文相关的表示来解决。

2.3 序列建模的瓶颈

这一时期的序列模型主要依赖 RNN 及其变体（LSTM、GRU）。它们通过隐藏状态在时间步之间传递信息，理论上可以建模任意长度的序列依赖。但实际训练中存在严重的梯度消失/爆炸问题，长距离依赖的建模能力受限。更关键的是，RNN 的序列计算特性导致无法并行化，训练效率低下。

三、预训练-微调范式（2018–2020）

3.1 Transformer：底层基础设施的突破

2017 年 Vaswani 等人的论文《Attention Is All You Need》提出了 Transformer 架构，彻底抛弃了 RNN 的序列计算，完全基于自注意力机制（Self-Attention） 建模任意两个位置之间的依赖关系。

自注意力的核心计算是：

Attention(Q, K, V) = softmax(QK^T / √d_k) V

其中 Q（Query）、K（Key）、V（Value）分别由输入序列经线性变换得到。多头注意力（Multi-Head Attention）通过并行计算多组注意力，捕捉不同子空间的语义关系。

Transformer 的优势在于：第一，自注意力直接建模任意位置对之间的依赖，不受序列距离限制；第二，矩阵运算可以完全并行化，训练效率大幅提升；第三，位置编码（Positional Encoding）弥补了丢弃序列归纳偏置带来的位置信息缺失。

3.2 BERT 与 GPT：两条路线的分野

2018 年出现了两条截然不同的预训练路线，它们的分歧源于对”预训练目标”的不同选择。

BERT（Bidirectional Encoder Representations from Transformers） 采用双向编码器架构。预训练目标是 Masked Language Model（MLM）：随机遮挡输入中 15% 的 token，让模型根据上下文预测被遮挡的词。这种双向上下文建模解决了 Word2Vec 的多义词问题——同一个词在不同上下文中的表示是不同的。

BERT 的下游适配方式是微调（Fine-tuning）：在预训练模型顶部添加任务特定的输出层（分类头、序列标注头），然后在下游任务的标注数据上进行有监督训练。这种方式大幅降低了下游任务的数据需求——不再需要从零训练，只需要在预训练基础上做少量调整。

GPT（Generative Pre-trained Transformer） 采用自回归解码器架构。预训练目标是 Causal Language Model（CLM）：给定前文，预测下一个 token。这种单向（从左到右）的生成目标天然适合文本生成任务。

GPT 的下游适配早期也使用微调，但它的核心优势在于生成能力。模型不仅能理解文本，还能产出连贯的长文本。

3.3 “预训练 + 微调”范式的意义

这一阶段的核心范式转变是：**从”每个任务一个模型”到”一个预训练模型 + 任务特定适配”**。预训练阶段在大规模无标注语料上学习通用的语言表示，微调阶段在少量标注数据上适配具体任务。这解决了传统 NLP 的两个根本问题：标注数据稀缺和跨任务知识无法复用。

但这一范式仍有局限：每个下游任务仍然需要单独的微调过程，需要维护多个模型副本；微调过程本身需要梯度计算，推理时模型结构因任务而异。

四、大语言模型时代（2020–至今）

4.1 从”微调”到”提示”的范式转变

2020 年 GPT-3 的发布标志着第二次范式转变。GPT-3 拥有 1750 亿参数，它证明了一个关键事实：当模型规模足够大时，可以通过上下文中的少量示例（few-shot）甚至零示例（zero-shot）完成新任务，不需要梯度更新。

这被称为上下文学习（In-Context Learning）。模型不再需要为每个任务微调独立的权重，而是通过提示词（Prompt）中的任务描述和示例，在推理时动态适配新任务。这把所有 NLP 任务统一为同一个过程：给定输入文本，生成输出文本。

4.2 规模法则（Scaling Laws）

Kaplan 等人（2020）和 Hoffmann 等人（2022）的研究揭示了大语言模型的一个反直觉特性：模型性能随参数量、数据量、计算量的增加呈现幂律提升，且在相当大的范围内没有出现平台期。

L(N) ∝ N^(-α)

其中 L 是损失函数，N 是参数量，α 是幂律指数。这意味着只要持续增加规模，模型性能就会持续改善。这一发现直接推动了从 GPT-3（175B）到 PaLM（540B）到 GPT-4 的规模竞赛。

4.3 涌现能力（Emergent Abilities）

当模型规模超过某个阈值时，会突然展现出训练时没有显式优化的能力。这些能力被称为涌现能力，包括：

  • 思维链推理（Chain-of-Thought）：通过逐步分解复杂问题，模型能够进行多步逻辑推理
  • 代码生成：根据自然语言描述生成可执行的程序代码
  • 多语言翻译：在只用少量语言对训练的情况下，实现跨语言零样本翻译
  • 上下文学习：从提示中的少量示例推断任务模式

涌现能力的不可预测性是大语言模型区别于传统模型的核心特征之一。传统模型的性能提升是渐进的、可预测的；大语言模型在规模跨越阈值时会出现质的飞跃。

4.4 理解与生成的统一

大语言模型的根本突破在于统一了理解和生成。传统 NLP 中，理解任务（分类、抽取）和生成任务（翻译、摘要）使用不同的模型架构和训练目标。大语言模型将所有任务转化为同一个目标：给定前文，预测下一个 token。

分类任务变成了”给定文本，生成类别标签”；翻译任务变成了”给定源语言文本，生成目标语言文本”；问答任务变成了”给定问题，生成答案”。这种统一不仅简化了模型架构，更重要的是让模型在预训练阶段学到的生成能力可以直接服务于理解任务。

五、三个维度的本质变化

回顾从 NLP 到大语言模型的演变，可以用三个维度概括其本质变化。

5.1 任务定义：从”多任务多模型”到”单任务单模型”

传统 NLP 的每个任务需要独立设计模型：分词用 CRF，情感分析用 LSTM + 分类头，机器翻译用 Seq2Seq + Attention。每个模型的输入输出格式、训练目标、评估方式都不同。

大语言模型将所有任务统一为文本到文本的转换。模型不区分”理解”和”生成”，只负责根据输入上下文生成最可能的后续文本。任务之间的差异体现在提示词的设计上，而不是模型结构上。

5.2 学习目标：从”判别式”到”生成式”

BERT 的目标是判别式的——给定输入文本，输出一个类别标签或序列标注。它擅长理解，但不擅长生成。

GPT 系列的目标是生成式的——给定前文，输出下一个 token。这种自回归目标天然统一了理解和生成：要正确预测下一个 token，模型必须理解前文的语义；而理解的结果直接体现为生成的文本。

5.3 知识获取：从”人工特征”到”自动学习”

传统 NLP 需要语言学家和工程师手动设计特征：词性标签、句法树结构、语义角色、实体类型。特征的质量直接决定了模型性能的上限。

大语言模型直接从原始文本中学习表示。预训练过程本身就是一个大规模的知识压缩过程——模型通过预测下一个 token，隐式地学习了语法规则、世界知识、逻辑推理模式。这些知识不是显式编码的，而是分布在数百亿参数的权重中。

六、未解决的问题

大语言模型并非终点。当前仍面临几个根本性挑战：

推理效率。自回归生成的逐 token 产出特性导致推理速度慢，无法并行。长文本生成的延迟和成本仍然是实际部署的主要瓶颈。

计算成本。大规模预训练需要数千 GPU 小时的计算资源，训练一次 GPT-4 级别模型的碳排放相当于数十辆汽车全生命周期的排放。

幻觉问题。模型会生成看似合理但事实错误的内容，因为它优化的是文本的统计似然性，而不是事实准确性。

可解释性。数百亿参数的分布式表示使得模型决策过程难以审计。在医疗、法律等高风险场景中，这是一个不可忽视的问题。

这些挑战也是当前研究的活跃方向。理解技术演变的脉络，有助于判断哪些问题是暂时的工程瓶颈，哪些是根本性的架构限制。
